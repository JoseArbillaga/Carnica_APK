# App de planta de CÁRNICA

Las versiones publicadas de la app Android de planta (`ar.com.carnica.planta`), una por release.

La app se actualiza sola: consulta a la API qué versión está publicada, baja el APK de acá y
verifica su SHA-256 antes de instalarlo. La instalación siempre la confirma el operario.

Para instalarla a mano en un equipo: abrir el enlace del APK de la última release desde el
navegador del equipo y aceptar la instalación. Todas las versiones van firmadas con el mismo
certificado, así que cada una se instala encima de la anterior sin perder datos.
